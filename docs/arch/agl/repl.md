# AgL REPL

`agm repl` evaluates one entry at a time with the same passes and runtime as `agm exec`. This document covers what makes it incremental.

## Incremental Sessions

`ReplSession` keeps a persistent environment: each entry is compiled and evaluated exactly once against accumulated declarations, bindings, imports, `use`s, fixities, and runtime values, so agent calls never replay.

- **File-mode equivalence.** An entry resolves in source order exactly as a file does; verdicts never depend on how source is split into entries.
- **Supersession.** A redeclaration at the same path is a fresh declaration identity; retained values, aliases, and methods keep the shape they were checked against. Imports and `use`s replace retained ones as scope decides.
- **Failure.** A runtime-failed entry promotes only what its initializer reached and leaves the prior generation intact. `check_only` entries check without evaluating or promoting.
- **State.** Each entry runs in a fresh interpreter; engine-setting writes persist as ordinary state, and the session hands its module and function seeds to every new interpreter. With no selected program to reach them from, every loaded module's parameters are seeded from their declaration routes, and one sharing a full spelling with a loaded parameter fails the entry.
- **Host lifetime.** One `HostSession` owns agent sessions, companion `runtime.state` ([execution/ffi.md](execution/ffi.md)), and the process host ([execution/runtime.md](execution/runtime.md)) shared by all entries: an entry runs in a host scope, so an uncaught raise or interrupt terminates only the processes that entry forked, while others stay attached across entries; `close` and `:reset` terminate all of them, then close agent sessions and companion state; `:reset` clears the environment and replaces the host, so no handle survives. A forked child honours the running entry's live `debug` setting and traces to its store.

## Retained Library Image

Every entry compiles a whole program, but library modules are compiled once: the session reuses each module's checked artifacts while the graph holds the same AST object; a fresh default-stdlib session without a parameter-seed resolver (so never `agm repl` itself) starts from a cached checked bootstrap image. Lowering allocates into a persistent `LinkImage` (`lower/repl.py`); allocations of modules a failed entry left incomplete are kept for reuse but never linked ([execution/lowering.md](execution/lowering.md#the-ir)).

## Front-End Seam

The UI-free `repl/loop.py` owns the loop, parameterized by a reader and writer. `repl/console.py` and `repl/themes.py` alone import prompt_toolkit: the console maps shared lexical [highlighting](../highlighting.md) categories using live type/constructor names, retaining legacy error fallback and line clipping. It does not run scope-resolved highlighting. Completion combines session state with the scanner's raw-quote compatibility check. `repl/plain_console.py` serves pipes, `TERM=dumb`, and `--plain`; Emacs uses it under `comint-mode` with independent font-lock.

## Introspection and Rendering

Entry results carry the compiled program's `ValueDescriptors`, so `repl/render.py` renders without a global registry. Echo is decided from the checked static type (unit echoes nothing unless `echo-unit`). `:info` resolves a spelling through scope's ordinary lookup and the checker's constructor selection, so it reports exactly what an entry would see (a session that has promoted nothing opens its library image first and remembers a rejected image until `:reset`, the first promotion, or any later entry; a hidden name reports the hiding rejection under its written name; builtin types read as types beside same-named modules and scopes). Session docs of superseded declarations are pruned after each promotion. An error reports every diagnostic through `AglError.diagnostics()`. A module-level `@!doc` in an entry or loaded file warns `unused-module-doc` (`entry_pipeline.py`); `load_file` keeps the file's leading `@!allow` names for every entry (`module_allowed_names`) and relocates each entry's results to file positions through its own source label (`entry.relocate`, `FileOrigin.place`; transcripts included), so earlier entries' places never shift; trace records, `:info` locations and runtime errors use the same placement (`ReplSession.user_place`: file position for loaded entries, else `<repl>`); inherited `@!allow` governs only warnings anchored in the entry's own source, and a transcript frames each entry with the `@!allow` names it ran under, so a replay keeps its governance; a plain file that does not parse runs as one entry (a transcript entry that does not parse fails alone), while an item that parses but cannot be converted to AST fails its own entry. Each entry's text is lexed once (`lexer.lex_source` returns a `LexedSource` recording the text, tokens, advisories and failure; no global memo): the front end lexes the buffer to classify it and hands that `LexedSource` through the loop to `eval_entry(lexed=...)`, so prompt classification, blank-entry detection, and every reading of the entry share the pass through `lex_replay`, which replays only for the very text it recorded; a statically rejected entry that lexed is re-read as a bare type from the program reading's tokens (`_settle_entry`), and a loaded file that is no program skips the program reading (`_eval_unparsed`). The classification parse is recorded on the `LexedSource` (`parses`) and reused by evaluation through `replayed_parse`, so an entry is parsed once from prompt to result; `load_file` parses the file once to a tree (`parser.ProgramTree`, no AST) and reads each entry, advisories included, off the file's one lex and parse (`parser.entry_slices`, `lexer.lexed_slices`); each entry is converted to AST once, by `eval_entry` with the session's continuing node ids, and the leading `@!allow` names, and the halted-load advisory regions, come from the header the first entry converted with itself (its program or bare-type probe), so the file's header is never converted apart; a plain file's entry begins its line, keeping the line's indentation, or, following another item on its line, is padded to the file's base indentation (`lexer.positions.entry_padding`, computed once per entry), so it reads, and is saved and reloaded, as it does in the file; each TAB advisory (its column a lexer column, like every diagnostic's) is the whole file's, owned by the one entry whose text starts last at or before it, and the entry reports it, governed by the file's `@allow` regions. A transcript is never lexed or parsed as a whole: its `# agm:entry:LEN` marks split it textually, and each entry is an input of its own, lexed and parsed alone exactly as typed, under its `allow=` marks and placed at its file position (`FileOrigin`), so no entry depends on the layout of its neighbours; a file with no items loads as one entry carrying its advisories. A load halted by a failing entry (plain file or transcript) reports the later entries' advisories with it, stamped with the file and governed as running the entries would: a plain file by the regions of the file's inner attributes and its unrun items, the only items converted outside an entry run (`ProgramTree.items_from`, then `scope.attributes.module_allow_regions` over them and the run entries' items, which leaves parameter zones unchecked); a transcript entry by its own `allow=` marks and the regions of its own attributes and items, from its own lex and, only when it has an advisory, its own parse (`_report_entry_advisories`; an entry that does not parse reports none); they are withheld when the failing entry never resolved (`EntryResult.scope_failed`). This differs from `agm check` both ways: an entry sees no later declaration (forward references), and the REPL accepts constructs check rejects at scope (bare expressions, bare type entries, redefinitions, imports after declarations), after which check reports no advisories but `:load` still does. A scope failure of an entry after the halt is unknown, and an entry failing only because the REPL runs items apart counts as unresolved. A bare type entry is parsed by the grammar's `type_entry` start (inner attributes, then the type) and checked as a probe program carrying those attributes; an exception base prints as a spelling writable at top level (`_base_spelling`: its own name or a top-level alias whose declared type is it, each confirmed by one display-free probe). Declaration `@doc` text comes from retained module attributes (session-promoted entries keep theirs in the session); a lone slash route reads as a module before a declaration, any other spelling as a declaration first, falling back to a module or scope region with its `@!doc` (`repl/info_docs.py`). Modules and scope regions are whatever scope's own qualifier lookup (`lookup_reached_origins` on a probe resolve's entry sources) reaches for the spelling (imports, uses, aliases, session regions); one source is described alone, several are each described under a source label (`repl/info_sections.py` shares the labels with the highlighter).

## Setting Persistence

`[repl]` settings (`theme`, `echo`, `echo-unit`) persist through one path: meta-commands report a change and `commands/repl.py` saves it via `config/general.py`. `--quiet` is session-only.

## Code Entry Points

- `src/agnette/agl/repl/session.py` — the incremental session; `entry_pipeline.py` — the incremental entry pipeline, reusing `PipelineDriver`'s host environment and helpers.
- `src/agnette/agl/repl/loop.py`, `console.py`, `plain_console.py` — the shared loop and front ends; `meta.py`, `render.py`, `info_docs.py`, `themes.py` — meta-commands, rendering, `:info` doc rendering, themes.
- `src/agnette/agl/lower/repl.py` — incremental linking.
- `src/agnette/agm/commands/repl.py` — the CLI host.
