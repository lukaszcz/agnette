# Agnette documentation

Agnette (Agentic Notation & Execution Toolkit) provides CLI agent management facilities
and a complete agent workflow DSL. **AgM (Agnette Manager)** manages agent-oriented
projects; **AgL (Agnette Language)** defines their workflows. Both use the `agm` executable.

- [Language reference](agl/reference/index.md) — AgL syntax, types, and workflow semantics.
- [Command reference](commands/index.md) — AgM commands, options, and configuration.
- [Architecture](arch/index.md) — system structure and codebase entry points.
